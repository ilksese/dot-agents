<task>
使用ego浏览器进行UI冒烟测试。

输入中可能包含两类链接：

- figma 设计稿链接（若存在，作为设计基准）
- localhost/127.0.0.1 待测页面链接（若存在，作为测试目标）

若两者都存在，以 figma 为基准对页面逐项比对；若只有其一，按实际存在的链接执行。

关注范围：文字字体、文字颜色、文字排版、元素尺寸、元素可交互区域、图标大小、图标颜色、图片尺寸、背景色、内外边距、文档流、圆角、边框、阴影、对齐方式、透明度、层级、交互状态（hover/active/focus/禁用态）、溢出与截断、响应式断点、动效、无障碍对比度。

比对规则（仅当 figma 链接存在时）：

- 逐项核对，记录每一项的期望值（figma）与实际值（页面）。
- 差异项标注严重程度：致命（影响功能/可交互）、明显（视觉偏差）、轻微（像素级）。

输出格式：

- 结论：通过 / 不通过。
- 差异清单：每项列出 关注点、期望值、实际值、严重程度、截图证据。
- 无差异项不列出。

兜底规则：

- 无 figma 链接：跳过基准比对，仅做功能冒烟测试，并说明缺少设计基准。
- 无待测页面链接：向用户询问待测页面地址。
